# Contributing

Thanks for helping improve the checklist. It works best when every item is something a non-expert builder can actually check.

## What makes a good item

- Specific and checkable — a reader can look at their app and answer yes or no.
- Written in plain English, with the "why" clear from the wording.
- Relevant to apps built with AI tools (Lovable, Bolt, v0, Cursor, Replit) and their Supabase or Firebase backends.

## Format

Add your item to the most relevant section as a checkbox:

```
- [ ] **Short imperative statement.** One sentence of context or how to check it.
```

Link to an authoritative reference where it helps, using an HTTPS URL.

## How to submit

1. Fork this repository.
2. Add or edit an item in the right section.
3. Open a pull request explaining what you changed and why.

By contributing, you agree that your contribution is released under [CC0](LICENSE), the same terms as the rest of the project.
